# Телефонный сервис

Сервис для хранения абонентов и истории звонков
У звонка есть участники и длительность и время создания
Один звонок может объединять нескольких абонентов

## Стек

- Go для бэкенда
- PostgreSQL для хранения абонентов и звонков
- OpenAPI и ogen для описания API и генерации серверного кода
- pgx и sqlc для подключения к БД и типизированных SQL запросов
- Goose для миграций
- Koanf для загрузки конфигурации
- Docker Compose для запуска приложения и БД
- OpenTelemetry и Prometheus для логов и метрик и трассировки

## HTTP API

- `GET /calls` возвращает звонки с данными участников
- `POST /call` создаёт звонок и возвращает его с участниками
- `GET /abonets` возвращает список абонентов

Путь `/abonets` сохранён для совместимости

### Создание звонка

Запрос содержит `participant_ids` и `duration` и `created_at`
Успешный ответ имеет код `201`

- Нужен хотя бы один существующий абонент
- Участники не должны повторяться
- Длительность может быть нулевой но не отрицательной
- ID звонка назначает БД

## Архитектура

### Ответственность слоёв

- Хендлер принимает HTTP запрос и формирует ответ
- Юзкейс управляет конкретным сценарием
- Сервис содержит общие бизнес-правила
- Репозиторий читает и сохраняет данные

Вызовы идут от хендлера через юзкейс и сервис к репозиторию
Слои не вызывают соседние компоненты и верхние уровни
